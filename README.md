## 🔄 My Data Analysis Workflow

`Collection → Cleanup → Exploration → Visualisation → Statistical Analysis`

| Stage | What I do | Tools |
|-------|-----------|-------|
| **Collection** | Import data from CSV/Excel files, databases and generated datasets | Excel, MySQL, Python |
| **Cleanup** | Handle missing values, remove duplicates, fix data types | pandas, NumPy, Excel |
| **Exploration** | Summary statistics, patterns, trends, outliers (EDA) | pandas, NumPy, SQL |
| **Visualisation** | Charts, KPIs and interactive dashboards | Excel, Power BI, Tableau |
| **Statistical Analysis** | Mean, median, correlation, grouping and comparisons | Python, NumPy, SQL |

## 🚀 How to Use This Repo

1. Clone the repository
   ```bash
   git clone https://github.com/rehan2641/<repo-name>.git
   ```
2. Install the Python libraries
   ```bash
   pip install numpy pandas jupyter faker openpyxl
   ```
3. Open the notebooks in `python/`, run the `.sql` files in MySQL Workbench, and open the `.pbix` / `.twbx` files in Power BI Desktop / Tableau.
